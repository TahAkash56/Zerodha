# 📈 Stock Trading & Portfolio Management Platform (Zerodha-like)

A full-stack **MERN-based stock trading and portfolio management platform** that provides real-time market data, portfolio analytics, and a secure trading experience. Inspired by platforms like Zerodha, this project focuses on clean architecture, scalability, and modern web development practices.

---

## 🚀 Features

- 🔐 **Authentication & Authorization**
  - JWT-based secure login and signup
  - Protected routes for authenticated users

- 📊 **Dashboard**
  - Real-time stock prices using live market APIs
  - User portfolio overview
  - Investment performance tracking

- 💼 **Portfolio Management**
  - Buy and sell stocks
  - Track holdings and transaction history
  - Portfolio analytics and insights

- 📈 **Data Visualization**
  - Interactive charts using **Chart.js**
  - Stock trends and portfolio allocation

- ⚙️ **Backend APIs**
  - RESTful APIs
  - CRUD operations with MongoDB & Mongoose

- 🧪 **Testing**
  - Unit and integration tests using **Jest**

---
